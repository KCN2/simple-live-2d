# Simple Live2D for Godot 4 (CharacterMorph2D) - v1.0

단 한 장의 2D 일러스트(PNG)로 실시간 호흡, 바스트 모핑, 머리카락 및 의상 흔들림 애니메이션을 구현하는 Godot 4 전용 모핑 애드온 및 GUI 에디터 도구입니다.

---

## ✨ 주요 기능

- **GUI 비주얼 에디터**: 드래그 앤 드롭 캔버스, 원형 인터랙티브 기즈모 조작, 2D 방향·세기 조이스틱 패드 제공.
- **좌우 비교 뷰 & 원본 토글**: 원본 이미지와 실시간 모핑 결과를 한 화면에서 비교 및 검토.
- **다중 변형 영역 지원**: 최대 8개의 독립 변형 부위 설정(영역별 방향, 세기, 팽창, 감쇠, 시차 개별 제어).
- **물리 탄성 스프링 시뮬레이션**: 스프링 강성(Stiffness)과 감쇠(Damping)를 적용한 통통 튀는 탄성 물리 효과 지원.
- **자유형 마스킹 브러시**:
  - 🧽 **보호 지우개**: 움직이면 안 되는 영역(외곽선, 신체 고정 부위 등)을 고정.
  - 🖌️ **변형 브러시**: 추가로 움직임을 줄 영역을 페인팅.
  - 마우스 줌 인/아웃 시에도 화면 픽셀 크기가 일정하게 유지되는 원형 커서 제공.
- **프리셋 자동 연계 로딩**: 이미지를 열면 동일한 이름의 JSON 프리셋 파일(`[이미지명].json`)을 자동으로 감지하여 함께 로드.
- **원본급 고화질 GIF 내보내기**:
  - Median-Cut 기반 255색 적응형 팔레트(Adaptive Palette) 인코딩.
  - 투명 배경 마스크 및 무손실 LZW 압축 지원.
  - 최대 1024px 고해상도 지원 및 멀티스레드 비동기 처리.

---

## 🚀 빠른 시작

1. Godot 4.x로 프로젝트를 열고 `res://demo/morph_test.tscn`을 실행합니다.
2. 상단 툴바에서 **🖼️ 그림 열기**를 누르거나 탐색기에서 이미지를 드래그 앤 드롭합니다.
3. 캔버스 위의 원형 기즈모와 우측 패널의 슬라이더/조이스틱으로 원하는 움직임을 조절합니다.
4. **💾 프리셋 저장**을 눌러 애드온용 JSON 파일로 저장하거나, **🎞️ GIF 저장**을 눌러 움직이는 고화질 GIF를 내보냅니다.
